# Version Information

TKJ Network Toolkit

## Current Module

IPv4 Calculator

## Status

Development Release

---

## V1.0.0 Scope

V1.0.0 introduces the initial IPv4 networking module with the following capabilities:

- IPv4 address validation
- CIDR prefix validation
- Subnet mask calculation
- Network address calculation
- Broadcast address calculation
- First usable host calculation
- Last usable host calculation
- Usable host calculation
- Total address calculation

The graphical interface is implemented using PyQt6.

---

## Compatibility

The project is intended to support Linux environments with distribution-specific handling for system dependencies.

Python dependencies are separated from system packages to improve portability across Linux distributions.

Alpine Linux uses its native package manager for PyQt6 installation where required.

---

## Versioning Scheme

TKJ Network Toolkit uses:

MAJOR.MINOR.PATCH

### MAJOR

Incremented for major architectural changes, incompatible changes, or major project milestones.

### MINOR

Incremented when new backward-compatible functionality or toolkit modules are introduced.

### PATCH

Incremented for bug fixes, corrections, and small improvements.

---

## Release Policy

A version should represent functionality that has been implemented and tested.

Experimental or incomplete features should not be treated as part of a stable release.

---

## Development Direction

The initial release establishes the IPv4 foundation of TKJ Network Toolkit.

Future releases may introduce additional networking modules, including IPv6, VLSM, DNS utilities, diagnostics, packet analysis, and other networking tools.
